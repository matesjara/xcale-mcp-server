## Backend note — MCP tool catalog visibility (resolved 2026-07-09)
A backend gap surfaced via the Cloudbeds pilot: connected MCP providers showed **0 tools** in the
agent tool catalog (`GET /api/agent/tools`) because that surface reads the GLOBAL `toolRegistry`,
while MCP tools only load into the per-run basket (ADR-0003). Fixed with a read-only projection —
see `xcale-backend/docs/design/mcp-client-runtime/gap-tool-catalog-visibility.md`. **Implication for
Siigo:** the fix is delivery-agnostic (`forwarded`/`reference` alike), so once Siigo is added to
`mcpToolboxes` and reaches a CONNECTED Rail A connection, **its tools appear automatically** — no
catalog-visibility work needed in B3–B5.
